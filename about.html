02 Despre acest portofoliu

Acest portofoliu prezinta proiectele mele publice si evolueaza impreuna cu activitatea de pe GitHub. Pagina de proiecte foloseste GitHub API pentru a afisa automat repository-urile, limbajele folosite si data ultimei actualizari.

Designul combina o structura editoriala cu elemente interactive, filtre si cautare pentru ca proiectele sa poata fi explorate usor.
